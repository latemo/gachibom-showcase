# 가치봄 | 무장애 제주 여행 판단 보조

이동 조건과 동행 상황에 맞춰 제주 여행 후보를 비교하고, 추천 이유와 접근성 정보의 확인사항을 함께 제시하는 프로젝트입니다. **가치봄 및 제주의마음** 작업을 소개합니다.

## 기술 스택·접근 방식

- **Python:** 추천 정책·점수 계산·근거 처리
- **웹 프런트엔드:** 여행 조건 입력, 추천 결과·지도·장소별 정보 표시
- **OpenAI API:** 서버 API를 통한 LLM 도움말 연결
- **RAG·BM25:** 구조화된 조건으로 장소 카드를 거른 뒤 근거 검색

## 주요 구현 범위

- 휠체어 이용·아이 동반·음식 제한·날씨 민감 상황을 고려한 후보 비교
- 접근성 정보, 이동 부담과 정보 확인 상태를 반영한 추천
- 적합 이유·감점 이유·방문 전 확인사항 제시
- 추천 정책과 LLM 문장 생성을 분리해 근거 범위를 제한

## 현재 단계와 한계

개발 프로젝트입니다. 공개 포트폴리오에는 2026-09-30 기준 고정된 여행 상황 5개의 정책 검사 통과 기록이 있습니다. 이는 현장 접근성, 이동 가능성이나 실제 이용 만족도를 보장하지 않습니다. 이번 문서 추가에서 운영 테스트를 재실행하지 않았습니다. 시설 정보는 방문 전 다시 확인해야 합니다.
